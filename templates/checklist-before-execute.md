# ✅ Checklist Sebelum Eksekusi

> Gunakan checklist ini sebelum AI mulai mengerjakan task apapun.

---

## 📋 Pre-Execution Checklist

### 1. Konteks Project
- [ ] Sudah baca dan pahami struktur project?
- [ ] Sudah tahu tech stack yang digunakan?
- [ ] Sudah tahu framework dan library yang ada?
- [ ] Sudah pahami coding style dan naming convention?
- [ ] Sudah cek konfigurasi (tsconfig, eslint, prettier, dll)?

### 2. Pemahaman Request
- [ ] Sudah paham apa yang diminta user?
- [ ] Sudah tanya semua detail yang kurang jelas?
- [ ] Sudah dapat jawaban untuk semua pertanyaan?
- [ ] Tidak ada asumsi yang belum dikonfirmasi?

### 3. Rencana Eksekusi
- [ ] Sudah buat rencana langkah-langkah?
- [ ] Sudah list semua file yang akan dibuat/diubah?
- [ ] Sudah jelaskan perubahan di setiap file?
- [ ] User sudah setuju dengan rencana?

### 4. Perubahan File Existing
- [ ] Sudah tunjukkan kode lama vs kode baru?
- [ ] Sudah jelaskan alasan perubahan?
- [ ] User sudah konfirmasi setiap perubahan?
- [ ] Tidak ada perubahan di luar yang diminta?

### 5. Scope & Batasan
- [ ] Hanya mengerjakan yang diminta?
- [ ] Tidak menambah fitur yang tidak diminta?
- [ ] Tidak install library baru tanpa izin?
- [ ] Tidak refactor/optimize yang tidak diminta?

### 6. Kualitas
- [ ] Kode mengikuti style yang ada?
- [ ] Naming convention konsisten?
- [ ] Kode complete dan functional?
- [ ] Tidak ada placeholder/TODO tanpa penjelasan?
- [ ] Sudah diverifikasi/di-test?

---

## ⚡ Quick Check (Versi Singkat)

Sebelum eksekusi, pastikan:
1. ✅ Konteks project sudah dipahami
2. ✅ Detail sudah ditanyakan dan dijawab
3. ✅ Rencana sudah dibuat dan disetujui
4. ✅ Perubahan sudah dikonfirmasi
5. ✅ Scope tidak melebihi yang diminta
6. ✅ Kode berkualitas dan complete
